# README asset guide

Replace the six placeholder SVGs in `assets/projects/` with your real project images.

Recommended format:
- 16:9
- 1200×675 or similar
- `.webp`, `.png`, or `.jpg`
- one strong gameplay screenshot or key art per project

Files to replace:
- `assets/projects/tuf.svg`
- `assets/projects/horror-fps.svg`
- `assets/projects/towerclash.svg`
- `assets/projects/blastbox.svg`
- `assets/projects/multiplayer.svg`
- `assets/projects/stranger-clicker.svg`

If you use a different filename, update the corresponding image path in `README.md`.

The repository supplied for this redesign contained only `README.md`, so no real project screenshots were available and no gameplay features were invented.
