# 🎮 About Me

I am a **Gameplay Programmer & Game Developer** with a passion for designing modular game architectures, fluid character controllers, and responsive game mechanics. I like turning ambitious design ideas into systems that actually ship — clean, testable, and fun to iterate on.

```yaml
role: Gameplay Programmer
focus: [C++, C#, Behavior Tree AI, Physics, Multiplayer Netcode, Performance]
engines: [Unity, Unreal Engine 5]
currently_building: TUF — The Ultimate Thief
currently_learning: [GAS (Gameplay Ability System), ECS/DOTS, Server-Authoritative Netcode]
fun_fact: "I debug gameplay bugs by acting them out in real life."
```

- ⚙️ **Core Focus:** C++ & C# gameplay systems, Behavior Tree AI, physics-based interactions, and performance optimization.
- 🛠️ **Engines:** Proficient in both **Unity** and **Unreal Engine**, taking projects from prototype to polished playable builds.
- 🧩 **Architecture:** Data-driven design with ScriptableObjects/Data Assets, event-driven systems, and clean separation between gameplay logic and presentation.
- 🌐 **Multiplayer:** Comfortable with server-authoritative design, client-side prediction, and lag compensation.
- 🎯 **Goal:** Building seamless player experiences through clean, maintainable code and robust game design patterns.
